# Dados do S Bank

Esta pasta **não é publicada** no GitHub Pages (veja `.github/workflows/pages.yml`). Mesmo assim, qualquer pessoa com acesso ao repositório consegue ler os arquivos daqui, então mantenha o repositório privado.
